Developed a custom C preprocessor that simulates the preprocessing phase of a C compiler.
Removes single-line (//) and multi-line (/* */) comments from source code.
Processes #include directives by inserting header file contents.
Supports object-like macro substitution using #define.
Implements function-like macro expansion with argument replacement.
Generates a preprocessed output file with a .i extension.
Demonstrates compiler design and lexical analysis concepts.
Utilizes file handling and string manipulation techniques in C.
Modular implementation with separate components for header inclusion, comment removal, and macro processing.
Helps understand how C source code is transformed before the compilation stage
